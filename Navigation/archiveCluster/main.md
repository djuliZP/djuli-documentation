# Archive Cluster

Move the selected cluster to the *Archived* view.

Archiving keeps the cluster and everything inside it (projects, reports, raw data) intact, but hides them from the *Active* view so the workspace stays focused on current work. The cluster's content remains searchable, shareable and restorable at any time.

Use this when an experimental campaign is complete and you want to clear it from your daily view without deleting it.
