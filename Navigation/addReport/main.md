# Add Report

Create a new report under the current project.

A report is one experiment: its metadata (operator, equipment, protocol), the raw files used, the analysis configuration, the produced plots and the analytics. After clicking this button you give the report a name and confirm; it then appears in the table and under the project in the navigation tree on the left.

You can also create a report indirectly by dropping raw files into an existing report's drag area, or by pushing data through the Djuli REST API.
