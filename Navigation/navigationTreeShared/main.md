# Shared Navigation Tree

The accordion tree showing every cluster, project and report that another Djuli user has shared with you.

Items here behave like your own: you can open them, run analyses, and view the analytics. Whether you can also **edit** the metadata or **delete** the report depends on the permission level the owner granted you (read, comment or edit).

To stop seeing a shared cluster — for example after a project finishes — select it and use the *Opt out* button on the toolbar (see [`optOutSharedCluster`](../optOutSharedCluster)). The cluster stays with the owner and other collaborators; only your access is removed.
