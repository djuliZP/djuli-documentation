# Reports Table

The table that lists every report inside the current project.

Each row is one report with its identifier, name, date of test, batch ID and operator. Click a row to open the report in the workspace; tick the checkbox to select it for batch actions on the toolbar (share, remove, compare, combine, download).

Use the *Search* input above the table to filter by report name, and the *page size* selector to control how many rows are shown per page.
