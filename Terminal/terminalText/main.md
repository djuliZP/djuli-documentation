# Terminal Log

The log area of the terminal panel.

Three kinds of message appear here:

- **Notifications** — errors, warnings and info messages emitted by Djuli (failed analyses, parsing problems, successful saves, share confirmations).
- **Command echoes** — the command you typed in the input box below, so you can see exactly what was sent.
- **Command responses** — the result of each [terminal command](./textInput), such as the list returned by `showChanges`.

Scroll back to inspect earlier messages. The log clears when you reload the page; if you need a persistent record, copy the relevant lines out before refreshing.
