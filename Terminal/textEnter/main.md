# Submit Command

Submits the command typed in the input box.

Pressing **Enter** (or clicking this icon) runs the command. The command is echoed in the [log area](./terminalText) above and its result appears immediately below the echo.

If the command is malformed or references an unknown data-line `id`, an error message is shown in the log instead of a result — fix the command and submit again. See [`textInput`](./textInput) for the list of available commands and their syntax.
