# Delta Fit

Use the *height* of the voltammetric peak relative to a local baseline (Δi) as the analytical signal instead of the absolute peak current.

This is the standard reading for voltammetry because the baseline current is rarely zero and often drifts between sweeps. Δi = peak current − baseline at the same potential, evaluated per peak and per concentration; the resulting Δi feeds the calibration curve.

The baseline used for the subtraction comes from Djuli's baseline correction step — review it under *Properties → VD → Baseline* before trusting the calibration.
