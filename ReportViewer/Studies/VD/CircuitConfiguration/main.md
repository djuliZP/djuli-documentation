# Equivalent Circuit Configuration

Define the electrical equivalent circuit model used to fit the impedance data in this Voltammetry Discrete study.

Each circuit element (resistor, capacitor, inductor, Warburg, constant phase element, …) corresponds to a physical or interfacial process at the sensor. Djuli will fit the model to the measured spectrum and report the value, the relative error and the goodness-of-fit for each element on the analytics card.

Use this when your discrete voltammetric experiment includes an impedance characterisation step. For studies that do not need a circuit model, leave this panel empty.
