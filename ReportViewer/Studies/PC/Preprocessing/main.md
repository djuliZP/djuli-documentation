# Preprocessing

The preprocessing pipeline applied to the chrono-potentiometric raw data **before** the fit runs.

Each step is configurable, and steps run in the order shown. Typical steps for this study type include **baseline correction**, **filtering** and **crop** to focus on the analytically relevant time window.

Preprocessed data is plotted alongside the raw data so you can see exactly what changed. Toggle individual steps off if you want to see how each one contributes; the fit (and analytics) recompute live.
