# Single Peak

When the chrono-amperometric trace contains more than one detectable step or feature, restrict the fit to a single one — the one you pick — and ignore the rest.

Use this when only one feature in the trace is analytically meaningful (for example, the second step after a pre-conditioning pulse) and you don't want the other features pulling the calibration.

The selected peak's height, position or area becomes the value plotted against concentration.
