# Purpose

Why this experiment was run.

Examples: *validate a new sensor batch*, *characterise an unknown analyte*, *troubleshoot a quality-control failure*, *generate calibration data for the next firmware release*. One short sentence is usually enough.

The purpose field is shown in the report header and helps reviewers (and future you) recognise the report's intent at a glance — useful when several reports in a project look similar at first scan.
