# Log Axis

Switches the axis between **linear** and **logarithmic** scales.

Useful when the data spans several orders of magnitude (impedance spectra, low-to-high concentration series, exponential decays). On a log axis, features that look squashed near zero become readable, while a single large value no longer dominates the plot.

Available on every unit panel — Time, Current, Potential, Impedance, Concentration and Generic X/Y. The toggle only affects the *plot*, never the stored data or the fit input.
