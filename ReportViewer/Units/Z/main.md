# Impedance (Z) Units

Pick the units used for the impedance axis on the current plot.

The *Input* dropdown sets the units Djuli expects the raw data to be in (what the instrument exported). The *Output* dropdown sets the units used to draw the axis. Djuli rescales between the two on the fly, so you can keep raw files unchanged and still present plots in the units that match your analysis convention.

The *Log axis* toggle switches the axis between linear and logarithmic scales - useful for impedance spectra that span several orders of magnitude.
