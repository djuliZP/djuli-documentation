# Processed Data Table

The table of data lines Djuli derived from your uploaded raw files. Each row corresponds to one data line plotted in the graphs.

Per row you can see and edit:

- **`id`** — the auto-assigned identifier used by [terminal commands](../../../Terminal/textInput) such as `flipx(id)`, `offsety(id, value)` and the others.
- **Color** — the line colour shown on the plot legend.
- **Label** — the legend text for this line.
- **Source file** — which uploaded file the line came from.
- **Visibility / actions** — hide, rename or remove the line.

Edits made here flow through to every plot in the report (raw, preprocessed, fit, comparison) and to the analytics card — there is no separate "apply" step.
